# What This Folder COntain

This Repository contain Complete OEE Project all Folders and File 

---

## 📂 Repository Structure

1) ESP32/: This Folder Contain ESPE32 S3 Microcontroller Running Code.

2) HMI/: This Folder Contain HMI Dispaly Interface UI Running Code.

3) Desktop_Application/: This Folder Contain Python and React code for View Data's in Dashboard, Graphs and also Store Data in Backend.

  --> backend/:   Python backend powered by FastAPI, Uvicorn, and SQLite.
  --> oee-ui/:    React + Vite frontend wrapped inside a Tauri environment.

## How to clone this project from Git and After Clone What to Do

Setp 01 : Copy the Respository Link in GitHub (eg : https://github.com/Rasu002/OEE-ESP32-FINAL_VERSION.git)

Step 02 : Create Empty New Folder In Desktop(eg: Folder Name "OEE ESP32 FINAL WORKING VERSION") and that Folder Open in VScode

Step 03 : In VScode Terminal Run "git clone https://github.com/Rasu002/OEE-ESP32-FINAL_VERSION.git"

step 04 : After Finish all needed folders and Files are downloaded in "OEE ESP32 FINAL WORKING VERSION" Folder

step 05 : Install "Espressif"(ESP-IDF) Extenstion in VScode. This Extenstion is Must need for Run ESP32 and HMI Projects

Step 06 : After Install That Extenstion Show in Down Left Side You Can perform tasks Like(Full Clean, Build, Flash, Monitor) using "EspressIf"
